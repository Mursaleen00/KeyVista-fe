We have 4 methods: 
- Get           This is used for fetch or get Data from API                      This is a Query
- Post          This is used for send or post Data from API                      This is a Mutation
- Patch         This is used for update or patch Data from API                   This is a Mutation
- Delete        This is used for remove or delete Data from API                  This is a Mutation

We use normally 2 functions:
- Fetch
- Axios


We have some this that use on APIs:
- Body
- Header
- Query                     ..../products?search=mobile&page=1&sort=min     1st query is use ? after that all queries uses &
- Params                    ..../products/9
